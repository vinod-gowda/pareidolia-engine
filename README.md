# pareidolia-engine

A frozen image of the open-source image engine used by Pareidolia Lab: AUTOMATIC1111 web UI v1.10.1 with the ControlNet extension and pinned Python packages, for a rented GPU. It contains no models, pictures or keys. Models are downloaded from Hugging Face when a machine starts.

Image: `ghcr.io/vinod-gowda/pareidolia-engine:latest`
